# CodeAlpha Hotel Reservation System

A Java-based Hotel Reservation System developed as part of the CodeAlpha Java Programming Internship.

## Project Description

The Hotel Reservation System is a console-based Java application that allows users to view available hotel rooms, book rooms, manage reservations, cancel bookings, and simulate payments.

The project demonstrates Object-Oriented Programming concepts and uses Java collections to manage rooms and reservations.

## Features

- View available hotel rooms
- Room categorization:
  - Single
  - Double
  - Deluxe
- Book a hotel room
- Generate a reservation ID
- View reservation details
- Cancel reservations
- Simulate payment
- Check payment status
- Make a cancelled room available again
- Console-based user interface

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Console-based application
